# 필요한 타일의 갯수 구하기

### [ 문제 ]

- TESTCASES 는 타일의 가로, 세로 길이를 뜻한다. 이 타일을 정사각형으로 붙인다.
- 이때 만들 수 있는 가장 작은 정사각형의 변의 길이와 필요한 타일의 갯수를 구한다.
- EXPECTED_VALUES 는 각각 변의 길이, 타일의 갯수를 뜻한다.
- 타일의 가로, 세로 길이를 뜻하는 정수 둘을 입력받아, 정사각형의 길이와 타일의 갯수를 정수형 배열로 반환하는 Main.solution(int, int) 메서드를 작성한다.

### [ 조건 ]
- 반환되는 배열의 0번 인덱스는 벽의 길이, 1번 인덱스는 타일의 갯수를 뜻한다.

### [ 예시 ]

|예시|->|출력|
|:---:|:---:|:---:|
|4, 5||20, 20|
|30, 14||210, 105|
