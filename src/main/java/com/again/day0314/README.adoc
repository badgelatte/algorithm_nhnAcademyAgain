= Browser History (using stack)

* Browser의 visit, forward, back 기능을 stack을 이용해서 구현합니다.
* Browser의 시작 페이지는 http://nhnacademy.com 입니다.

----
welcompage = "http://nhnacademy.com"
visit("http://payco.com")
back(2)
이면
http://nhnacademy.com 이 출력됩니다.
