# [병합정렬](https://en.wikipedia.org/wiki/Merge_sort)

### [ 설명 ]

- [분할 정복(divide and conquer) 알고리즘](https://en.wikipedia.org/wiki/Divide-and-conquer_algorithm)
    - 반복적으로 문제를 단순해지도록 나눠, 하위 문제를 결합해 문제를 해결하는 방법
- 분할 정복 방식을 사용해 데이터를 분할하고 분할한 집합을 정렬하며 합치는 알고리즘
- 시간 복잡도 : O(nlogn)
  <br/><br/>

1. 배열을 가장 작은 단위 요소(1개)가 될 때까지 나눕니다. **(divide)**<br/>
   [7], [4], [2], [5], [3], [1], [8], [9]

2. 나눠진 요소를 인접한 요소끼리 비교합니다.<br/>
   [7][4], [2][5], [3][1], [8][9]<br/>
   -> [4][7], [2][5], [1][3], [8][9]

3. 다시 인접한 요소끼리 비교합니다. <br/>
   예를 들어 아래와 같은 요소가 있다면,<br/>
   [4][7], [2][5]<br/>
   각 집합의 가장 앞에 있는 값은 해당 집합에서 가장 작은 값이기 때문에 앞에서부터 비교합니다.
    1. 4 vs 2
       [2]
    2. 4 vs 5
       [2], [4]
    3. 5 vs 7
       [2], [4], [5]
    4. 마지막 남은 요소 추가
       [2], [4], [5], [7]

4. 원래 크기의 묶음이 될때까지 2,3 과정을 반복합니다. **(conquer)**

### [ 문제 ]

- 주어진 문자열을 병합 정렬으로 오름차순 정렬합니다.

### [ 조건 ]

- Arrays.sort() 사용 금지
- 구현은 고민해보며 자유롭게 하셔도 됩니다. 재귀로도 풀 수 있습니다.
