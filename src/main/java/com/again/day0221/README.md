# 삽입 정렬 심화

### [ 문제 ]

- 배열 [4, 2, 3, 5, 1] 이 입력값으로 주어지고 삽입 정렬을 이용하여 다음을 수행합니다.
- 테스트 코드는 Main 클래스의 add(int) 메서드를 이용하여 정수 값을 하나씩 오름차순으로 저장하고, 각 원소가 저장되는 인덱스가 반환되면 그것을 리스트에 저장한다.
- 모든 원소를 추가한 후, 리스트 actual 의 기댓값은 다음과 같다. [0, 0, 1, 3, 0]

#### 과정 예시
1. [4, 2, 3, 5, 1] 의 첫번째 원소인 4를 저장한다. 현재 배열은 비어있기 때문에 첫번째인 0번에 저장된다
    - array : [4],  actual : [0]
2. [4, 2, 3, 5, 1] 의 두번째 원소인 2를 저장한다. 이미 저장되어있는 4보다 작기 때문에 첫번째인 0번 인덱스에 저장된다.
    - array : [2, 4],  actual : [0, 0]
3. [4, 2, 3, 5, 1] 의 세번째 원소인 3를 저장한다. 3보다 작은 2가 0번 인덱스에 저장되어 있기 때문에 1번 인덱스에 저장된다.
    - array : [2, 3, 4],  actual : [0, 0, 1]
4. [4, 2, 3, 5, 1] 의 네번째 원소인 5를 저장한다. 5보다 작은 4가 2번 인덱스에 저장되어 있기 때문에 3번 인덱스에 저장된다.
    - array : [2, 3, 4, 5],  actual : [0, 0, 1, 3]
5. [4, 2, 3, 5, 1] 의 다섯번째 원소인 1를 저장한다. 현재 배열에 존재하는 값들 중 가장 작은 값이기 때문에 0번 인덱스에 저장된다.
    - array : [1, 2, 3, 4, 5],  actual : [0, 0, 1, 3, 0]

### [ 조건 ]

- Main 클래스의 add(int) 메서드는 이미 작성되어있습니다. solution(int[]) 메서드를 작성하세요.

### [ 예시 ]

|          입력           | -> |          출력           |
|:---------------------:|----|:---------------------:|
|    [4, 2, 3, 5, 1]    |    |   [ 0, 0, 1, 3, 0]    |
| [3, 1, 6, 7, 4, 2, 8] |    | [0, 0, 2, 3, 2, 1, 6] |
