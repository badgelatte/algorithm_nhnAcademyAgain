# 버블정렬

### [ 문제 ]

```java
    for (int i = 0; i < array.length; i++) {
      boolean changed = false;
      for (int j = 0; j < array.length - 1; j++) {
        if (array[j] > array[j + 1]) {
          changed = true;
          swap(array[j], array[j + 1]);
        }
      }
      if (!changed) {
        System.out.println(i);
        break;
      }
    }
```

위와 같은 버블 정렬 방식으로 정렬을 시도할 때, 출력되는 i 값이 무엇인지 찾는다.  
테스트의 입력값은 정렬되기 전 배열과 정렬된 후의 배열입니다.
입력에 사용되는 배열의 정렬 방식은 오름차순, 내림차순 모두 있습니다.

-

### [ 조건 ]

- 직접 정렬을 하여 구하는 문제가 아닙니다.
- 버블 정렬을 할 때 발생하는 규칙을 잘 살펴보세요.
