# 버블정렬

### [ 문제 ]

- 주어진 배열을 특정 인덱스를 제외시키고, 나머지는 버블정렬을 이용해 오름차순 혹은 내림차순으로 정렬합니다.

![bubbleSort](./bubble_sort.gif)


### [ 조건 ]

- Arrays.sort() 사용 금지

### [ 예시 ]

|                        입력                        | -> |                출력                 |
|:------------------------------------------------:|----|:---------------------------------:|
| [ 5, 7, 2, 9, 10, 6, 1, 3, 4, 8 ] , [4, 9] , ASC |    | [ 1, 2, 3, 4, 10, 5, 6, 7, 9, 8 ] |

|                           입력                            | -> |                출력                |
|:-------------------------------------------------------:|----|:--------------------------------:|
| [ 6, 1, 3, 4, 8, 5, 7, 2, 9, 10 ] , [0, 2, 6, 7] , DESC |    | [ 6, 10, 3, 9, 8, 5, 7, 2, 4, 1] |
