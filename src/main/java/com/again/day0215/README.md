# 시간 복잡도 + 정렬

## 시간 복잡도

- 시간 복잡도 : 문제를 해결하기 위한 연산 횟수
- 표기 유형
    1. Ω(n) : 빅 오메가, 최선일 때
    2. θ(n) : 빅 세타, 보통일 때
    3. O(n) : 빅 오, 최악일 때
- 예시
  ```java
  public class Ex {
    public void ex() {
      // 1~100 사이 랜덤
      int random = (int)(Math.random() * 100);
      for (int i = 1; i <= 100; i++) {
        if (i == random)
          return;
      }
    }
  }
  ```
  | 최선   |    보통    |  최악   |
    |:-:|:--------:|:-----:|
  | Ω(1) |  θ(n/2)  | O(n)  |


## 버블 정렬

- 인접 요소를 비교해 swap 하는 정렬
- 시간 복잡도 : O(n^2)
